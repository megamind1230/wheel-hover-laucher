* 2026-11-14

** Changed

- Hover behavior: plain hover is highlight-only (never launches).
  Dwell auto-launch runs only while **Ctrl or Alt is held**. Releasing
  the modifier cancels a pending launch. Ctrl/Alt + click still
  launches explicitly.
- Removed ~autoLaunch~ config flag — dwell no longer gated by it
  (plain hover cannot launch, so the old safety flag was blocking the
  only hover-launch path). Ctrl/Alt + hover always dwells.
- Default ~hoverDelay~ 500ms → **250ms** (snappier dwell).
- KeyMap.js: ~shouldDwell(modifierHeld, highlightIndex)~ (no
  autoLaunch arg); shell.qml forwards Ctrl/Alt press/release to
  ~wheel.setDwellModifier~.
